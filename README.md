# Po trochu – notowania

Codzienne kursy zamknięcia dla aplikacji **Po trochu**, pobierane przez GitHub Actions (pn–pt wieczorem).
Lista instrumentów w `universe.json` jest celowo szeroka i nie odzwierciedla niczyjego portfela.
Dane pochodzą z publicznych wykresów Yahoo Finance i służą wyłącznie do użytku osobistego, niekomercyjnego.
